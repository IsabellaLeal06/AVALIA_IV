# Metodologia Scrum – Projeto Avalia+

## 1. Introdução

O desenvolvimento do Avalia+ utiliza o framework **Scrum** para organizar as atividades, acompanhar o progresso e permitir ajustes durante a evolução do projeto.

A equipe possui três integrantes e, devido ao tamanho reduzido do grupo, os integrantes acumulam funções de Scrum com responsabilidades técnicas.

## 3. Artefatos

### Product Backlog

Lista priorizada de tudo que precisa ser realizado no projeto.

### Sprint Backlog

Conjunto de itens selecionados para execução durante uma sprint.

### Incremento

Conjunto de itens concluídos que atendem à Definition of Done.

## 4. Sprints

Cada sprint possui duas semanas de duração.

O projeto possui sete sprints, iniciadas em 18 de agosto de 2026 e encerradas em 21 de novembro de 2026.

## 5. Cerimônias

### Sprint Planning

Realizada na primeira segunda-feira de cada sprint.

**Objetivo:** selecionar os itens do Product Backlog que formarão o Sprint Backlog e distribuir os responsáveis.

### Daily Scrum

Realizada de forma assíncrona por mensagem no grupo, conforme o planejamento do projeto.

Cada integrante informa:

- o que realizou;
- o que pretende realizar;
- o que está bloqueando seu trabalho.

### Sprint Review

Realizada na última sexta-feira de cada sprint.

**Objetivo:** apresentar o incremento produzido e validar os itens concluídos.

### Sprint Retrospective

Realizada após a Sprint Review.

**Objetivo:** identificar o que funcionou, o que não funcionou e quais ajustes devem ser realizados na próxima sprint.

## 6. Cronograma

| Sprint | Foco |
|---|---|
| S1 | Requisitos, regras de negócio e repositório |
| S2 | Modelagem e documentos do banco |
| S3 | Banco físico, API e autenticação |
| S4 | Cadastros e banco de questões |
| S5 | Simulados, correção e desempenho |
| S6 | Gamificação, acessibilidade e documentação |
| S7 | Mobile, integração e ajustes finais |

## 7. Corte documental

A documentação acadêmica deve estar concluída até o final da Sprint 6.

A Sprint 7 é reservada para código, integração e testes finais, sem inclusão de novos itens no documento acadêmico.
