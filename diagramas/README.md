# Diagramas — Avalia+

Esta pasta reúne os diagramas utilizados para representar a estrutura e o funcionamento do sistema Avalia+.

## Organização

- `banco-de-dados/`: diagramas relacionados à modelagem do banco de dados.
- `uml/`: diagramas UML utilizados na representação do sistema.

## Objetivo

Facilitar a compreensão da arquitetura, dos dados e das interações entre os componentes do sistema.

## Manutenção

Mantenha os diagramas organizados e atualizados conforme as decisões e alterações realizadas no projeto.
