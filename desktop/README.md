# Aplicação Desktop — Avalia+

Esta pasta reúne a solução da aplicação desktop do projeto Avalia+, desenvolvida em C# com Windows Forms.

## Estrutura

A solução está organizada em projetos com responsabilidades distintas:

| Projeto | Responsabilidade |
|---|---|
| `Avalia.Desktop` | Aplicação desktop e elementos relacionados à interface. |
| `Avalia.Desktop.Core` | Componentes centrais, modelos, interfaces, serviços e validações. |
| `Avalia.Desktop.Data` | Componentes relacionados ao acesso e à persistência de dados. |

O arquivo de solução `Avalia.Desktop.sln`, caso presente nesta pasta, permite abrir os projetos em conjunto no Visual Studio.

## Tecnologias

- **Linguagem:** C#.
- **Interface gráfica:** Windows Forms.

## Como abrir

1. Clone ou baixe o repositório.
2. Abra o arquivo de solução `.sln` no Visual Studio.
3. Verifique se todos os projetos e suas dependências foram carregados corretamente.
4. Confira as configurações necessárias para executar a aplicação.
5. Selecione o projeto de inicialização apropriado e execute-o.

Os passos de configuração e execução podem variar conforme o estado atual do desenvolvimento.

## Organização do código

A separação em projetos facilita a organização das responsabilidades e a manutenção da aplicação desktop.
