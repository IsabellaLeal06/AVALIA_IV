
# 📋 Product Backlog — Avalia+

O Product Backlog reúne e prioriza o trabalho necessário para desenvolver o **Avalia+** no PIM IV. Ele abrange requisitos, regras de negócio, modelagem, infraestrutura, funcionalidades, testes e documentação acadêmica.

## 🎯 Objetivo

Manter uma visão organizada do escopo do projeto, apoiando a priorização pelo Product Owner e a seleção dos itens que serão trabalhados em cada Sprint Planning.
