
# 💬 Dailys — Sprint 1

**Período:** 18/08 – 29/08/2026  
**Foco da sprint:** Requisitos, regras de negócio e repositório

Esta pasta reúne os registros de acompanhamento diário da Sprint 1 do projeto Avalia+.

## 📝 Como consultar os registros

Os arquivos de Daily desta sprint devem documentar o andamento real das atividades, incluindo:
- o que cada integrante realizou;
- o que pretende realizar em seguida;
- impedimentos ou pontos que precisam de alinhamento.

Os registros seguem o formato assíncrono adotado pela equipe. Consulte os arquivos desta pasta para visualizar as atualizações individuais de cada dia.
