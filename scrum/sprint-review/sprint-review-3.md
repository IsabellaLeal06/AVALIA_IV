# Sprint Review – Sprint 3

**Projeto:** Avalia+  
**Período da Sprint:** 15/09 a 26/09/2026

---

# Objetivo da Sprint

Construir a infraestrutura técnica do sistema Avalia+, implementando o banco de dados físico, a API e o mecanismo de autenticação dos usuários.

---

# Atividades realizadas na Sprint

Durante a Sprint 3 foram realizadas as seguintes atividades:

- Desenvolvimento do Script DDL do banco de dados.
- Configuração das restrições de domínio e unicidade.
- Inserção da carga inicial de perfis e medalhas.
- Estruturação da API em camadas.
- Implementação dos endpoints REST.
- Desenvolvimento da autenticação com hash de senha e token.
- Implementação da recuperação de senha por e-mail.
- Desenvolvimento da funcionalidade de login por perfil.
- Produção da etapa de Responsabilidade Social da documentação.

---

# Entregas da Sprint

Ao final da Sprint 3 foram entregues:

- Banco de dados físico criado.
- API estruturada.
- Endpoints de autenticação funcionando.
- Login por perfil implementado.
- Recuperação de senha implementada.
- Massa inicial de dados cadastrada.

---

# Avaliação da Sprint

A Sprint 3 representou a primeira entrega técnica do projeto. A infraestrutura necessária para comunicação entre as plataformas foi criada, permitindo autenticação segura dos usuários e integração futura com Web, Desktop e Mobile.
