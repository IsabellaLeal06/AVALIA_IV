# Sprint Retrospective – Sprint 3

**Projeto:** Avalia+  
**Período da Sprint:** 15 de setembro a 26 de setembro de 2026

---

# Objetivo da Retrospectiva

A Sprint Retrospective da Sprint 3 teve como objetivo analisar o desenvolvimento da infraestrutura do sistema, incluindo a criação do banco de dados, estrutura da API e autenticação dos usuários.

---

# O que funcionou bem

* Estruturação inicial do banco de dados físico.
* Criação das tabelas conforme o modelo lógico.
* Implementação das restrições de unicidade e integridade.
* Organização da API em camadas.
* Desenvolvimento do fluxo de autenticação por perfil.
* Definição da carga inicial de dados do sistema.

---

# Dificuldades encontradas

* Ajustes na implementação das regras de autenticação.
* Validação dos relacionamentos entre entidades durante a criação do banco.
* Necessidade de revisar o fluxo de recuperação de senha.
* Pequenos ajustes na integração entre API e banco de dados.

---

# Mudanças na equipe

Não houve mudanças na equipe durante esta Sprint. As atividades seguiram a distribuição definida no planejamento do projeto.

---

# Melhorias para a próxima Sprint

A equipe definiu como melhorias para a Sprint 4:

* Avançar para a implementação dos cadastros institucionais utilizando a API criada.
* Validar todos os endpoints antes da integração com as telas.
* Registrar testes de autenticação e acesso por perfil.
* Organizar melhor as evidências dos testes técnicos.

---

# Conclusão

A Sprint 3 representou um avanço importante na infraestrutura do Avalia+, estabelecendo a base técnica necessária para as funcionalidades principais do sistema. A conclusão da autenticação e da estrutura da API permitiu iniciar a implementação dos módulos administrativos na Sprint seguinte.
