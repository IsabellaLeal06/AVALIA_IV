# Sprint Retrospective – Sprint 1

**Projeto:** Avalia+  
**Período da Sprint:** 18 de agosto a 29 de agosto de 2026

---

# Objetivo da Retrospectiva

A Sprint Retrospective da Sprint 1 teve como objetivo analisar o processo de trabalho da equipe durante a primeira etapa do desenvolvimento do projeto Avalia+, identificando os resultados obtidos na revisão dos requisitos, na organização inicial do projeto e na definição da estrutura que servirá de base para as próximas Sprints.

---

# O que funcionou bem

* Revisão dos requisitos funcionais (RF01 a RF07).
* Revisão dos requisitos não funcionais (RNF01 a RNF07).
* Atualização das regras de negócio para a versão 2.2 do projeto.
* Criação das matrizes de rastreabilidade entre requisitos e regras de negócio.
* Alinhamento entre os requisitos e o Modelo Entidade-Relacionamento (MER).
* Definição do escopo de melhorias do PIM IV em relação ao PIM III.
* Definição das telas de cada plataforma (Web, Desktop e Mobile).
* Padronização da estrutura do repositório GitHub e organização inicial do projeto.
* Revisão do diagrama de casos de uso conforme os requisitos atualizados.

---

# Dificuldades encontradas

* Identificação de divergências entre o documento de requisitos e o MER do projeto anterior.
* Necessidade de revisar regras de negócio para manter consistência entre todos os documentos.
* Organização das alterações da versão 2.2 sem comprometer a estrutura já existente do PIM III.
* Alinhamento das responsabilidades da equipe para o início das próximas etapas do projeto.

---

# Mudanças na equipe

Durante a Sprint 1 não ocorreram alterações na composição da equipe.

A equipe permaneceu organizada da seguinte forma:

* **Isabella Santos Leal** — Scrum Master, responsável pela organização do projeto, documentação, banco de dados e gerenciamento do GitHub.
* **Gabriel Vinicius** — Product Owner, responsável pela definição do escopo das funcionalidades e desenvolvimento do Front-end.
* **Letícia Aparecida** — Desenvolvedora, responsável pelos diagramas UML e pelo desenvolvimento da API e da aplicação Desktop.

Essa divisão foi definida no início do projeto e passou a orientar a distribuição das atividades ao longo das Sprints.

---

# Melhorias para a próxima Sprint

Para melhorar o andamento do projeto na Sprint 2, a equipe definiu as seguintes ações:

* Finalizar a conferência do Modelo Entidade-Relacionamento com os requisitos atualizados.
* Atualizar o DER, o Modelo Lógico e o Dicionário de Dados para a versão 2.2.
* Revisar os diagramas de Classes e de Sequência conforme as mudanças dos requisitos.
* Iniciar a elaboração das primeiras etapas da documentação do PIM IV.
* Manter a organização das tarefas e das Dailys durante toda a Sprint.

---

# Conclusão

A Sprint 1 foi responsável por estabelecer toda a base organizacional e documental do projeto Avalia+.

Durante essa etapa, a equipe consolidou os requisitos, revisou as regras de negócio, definiu o escopo das melhorias do PIM IV e organizou o repositório do projeto. Com os documentos alinhados e o planejamento estruturado, o projeto ficou preparado para iniciar a etapa de modelagem e documentação do banco de dados na Sprint 2.
