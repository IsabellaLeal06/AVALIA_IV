## Cerimônias

- **Planning:** define objetivo, escopo e atividades previstas.
- **Daily Scrum:** acompanha progresso, próximos passos e impedimentos.
- **Review:** registra o incremento e os resultados alcançados.
- **Retrospective:** registra aprendizados e ações de melhoria.

Os índices de cada pasta apontam para os documentos disponíveis no repositório. Quando novos arquivos forem adicionados, os respectivos índices poderão ser atualizados. Os registros devem refletir o trabalho real; planejamento não é evidência de conclusão.
